Shared offline TeX Live toolchain

The prebuilt image is a shared toolchain for repositories that own their own
manuscript sources, build scripts, bibliography handling, and output names.
It does not contain manuscripts and does not install packages or download
dependencies while compiling. Consumers pin the verified image digest from
ci/texlive/image.txt; pull requests never publish images.

Run a repository's build script in its own workspace with:
  bash scripts/build_manuscript_container.sh WORKSPACE -- bash BUILD_SCRIPT

Examples:

Solver manuscript (build_paper.sh preserves its BibTeX procedure):
  bash scripts/build_manuscript_container.sh . -- bash build_paper.sh

Radon manuscript (paper.tex and paper.pdf are local to manuscript/):
  bash scripts/build_manuscript_container.sh manuscript -- bash build_paper.sh

Another project with a differently named main file and its own build script:
  bash scripts/build_manuscript_container.sh /path/to/project -- bash build-report.sh

Or invoke TeX directly when that is the repository's complete build procedure:
  bash scripts/build_manuscript_container.sh /path/to/project -- \
    pdflatex -interaction=nonstopmode -halt-on-error analysis-report.tex

The generic interface imposes no paper.tex, references.bib, paper.pdf, or
paper.log naming convention. Outputs are written into the bind-mounted host
workspace and owned by the invoking UID/GID. Use the repository's own build
script when it needs multiple TeX passes, BibTeX/Biber, or custom output names.

For compatibility, running the launcher without a command still invokes
abs-build-manuscript, the original solver-manuscript helper. New consumers
should pass their own command explicitly.

Every container run uses no network, a read-only root filesystem, no Linux
capabilities, no-new-privileges, and the invoking host UID/GID. A private GHCR
package requires read access for each consuming repository's Actions token;
grant repository workflow access in GHCR package settings without placing
credentials in the image.

Toolchain publication records the image digest and installed package list.
The prior package ghcr.io/metronforge/affine-bundle-solver-texlive and its
versions are retained as historical provenance; current usage is
ghcr.io/metronforge/texlive-custom.
