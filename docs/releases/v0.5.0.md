# Affine Bundle Solver v0.5.0 — Scientific v2

Scientific v2 is the second version of the same published research output. The
software version follows the repository's pre-1.0 policy; it is `v0.5.0`, not
`v2.0.0`.

## Scientific changes

- Operational classification, candidate quality, nearby-system certification,
  and exact-source status remain distinct evidence types.
- The split solve/check/certify API supports solving now and checking or
  certifying a caller-supplied candidate later. Candidate checking and deferred
  certification consume the supplied vector and do not solve again.
- The existing operational-policy API and independently verified certificate
  profiles are retained and strengthened.

## Public API

The primary solve entry point is `bsolve`; `bsolve_ex` exposes versioned
`BSSolveOptionsV1` controls. `abs_check_candidate` evaluates the quality of an
arbitrary supplied candidate, and `bs_certify_candidate` evaluates its
nearby-system certificate. Existing legacy router and certified APIs remain
available.

## Verification and qualification

- Frozen 36-system SLAE corpus and 180-call legacy qualification.
- Independent solution and candidate-quality oracles.
- CNF-derived MC/DC, API/ABI, caller-supplied-candidate, and solve/check/
  certification composition qualification.
- Portable/native, cross-platform, and BLAS-independence agreement.
- Installed external consumers, allocation-failure paths, ASan, and UBSan.

These are qualification results for the tested corpus and configurations; they
do not imply exhaustive coverage of all matrices, platforms, or failure paths.

## Correctness fix

The compact DGESDD fallback could run after partial infinite-witness allocation
failure and write through a cleared witness vector. Fallback entry is now gated
on successful witness preparation; deterministic allocation-failure and
sanitizer regressions protect that path.

## Binary SDK packaging fix

The packaged SDK now includes all installed public headers, including
`include/affine_bundle/solve.h` and
`include/affine_bundle/candidate_check.h`. The release qualification checks the
header inventory and consumes the packaged SDK bytes.

No new performance results are claimed. Retained timing evidence remains tied
to its existing immutable benchmark package and provenance.
