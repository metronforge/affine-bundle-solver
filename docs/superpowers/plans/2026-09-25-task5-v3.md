> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-contained, deterministic v3 campaign with corrected oracles, null-`xt` combined harness, and bounded small-case evidence.

**Architecture:** An independent local Python package generates its own manifest and ledger, materializes analytic synthetic matrices, calls the frozen solver libraries, and emits identity-pinned results with disjoint timing phases. Historical Task-5 artifacts are design references only.

**Tech Stack:** Python 3.13, NumPy, SciPy, pytest, CMake/GCC system BLAS/LAPACK, Git.

**Spec:** `docs/superpowers/specs/2026-09-25-task5-v3-design.md`

- Solver source commit is `29a0401d92e4ba7c9197b71be5304d816af87957`; local and remote main must match.
- Never touch `stash@{0}`, historical archives, solver source, GitHub, or publication claims.

- Tests precede behavior changes; all writes use `apply_patch` except atomic generation outputs.

## Review Focus

- Duplicate or malformed slot: generator must reject it before writing.
- Zero-scale oracle: relative cutoff must be exactly zero.
- Wide null-`xt` call: all retained semantic fields must match reference `xt`.
- Nested timers: summed disjoint phases must not exceed case wall time.
- Identity mismatch: runner must refuse stale libraries or manifest/ledger.
