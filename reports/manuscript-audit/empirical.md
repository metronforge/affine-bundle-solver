# Независимая проверка экспериментов

**Решение.** Сохранить численные статусы и времена из обеих печатных таблиц как исторические наблюдения. Исправить объяснение 155 диагностик и утверждение о точной совместности вещественного примера 48×8. В приложениях явно указать, где речь идёт об аналитическом ранге, оценке маршрутизатора и точных сохранённых данных. Для обеих невлитых веток возможна отдельная иллюстрация с собственным базовым SHA и знаменателем.

## Что воспроизведено

Текст, исходники и чистая нативная сборка взяты из `1df77461faf407320dab200d025fa846b2151502`. Повтор выполнен на AMD EPYC 9V74, GCC 14.2.0, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, mpmath 1.3.0. Библиотеки собраны через `./build.sh`. Использованы один поток OpenMP и BLAS, для двух примеров приложения четыре потока OpenMP согласно их протоколу. Ни один замер этого повторения не подменяет время ноутбука. [Манифест и фактический вывод](evidence/empirical-rerun.txt)

Из корня аудита, где `/tmp/manuscript-main` — уже собранное чистое дерево BASE, проверяются записи, прямые вызовы и новые точные оракулы:

## Две невлитые ветки

Пересчёт использует `git show SHA:path`, читает только `blocks` и игнорирует сохранённый `summary`. В каждом из восьми парных свежих процессных блоков берётся медиана трёх batch-времён на сторону, затем по размеру — отношение медиан FINAL/BASE по блокам. Семейное значение — геометрическое среднее трёх отношений с равным весом. Для 95%-интервала по одним и тем же индексам восстанавливаются пары и размеры, seed 42, 4 000 или 5 000 повторов соответственно. Оба опыта проведены на AMD EPYC 9V74, GCC 14.2.0, SciPy OpenBLAS 0.3.30, с привязкой к CPU 1, одним потоком BLAS/OpenMP и чередованием порядка версий. Температура и частота VM не контролировались.
