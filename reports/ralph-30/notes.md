# Side findings

- **Verified, API boundary.** The historical synthetic-reference.csv reports DGELSY/router. The public bsolve also reconstructs x on the raw matrix. On w2 this takes about 6 ms before and after A. See [base trace](data/profile-base-w2.txt) and [A trace](data/profile-a-w2.txt).
- **Verified, attempts versus growth.** On w3 there are four probe growths, and both later QR results on BASE have rank 256. A removes one proof attempt without changing the insertion/validation decisions. See [base trace](data/profile-base-w3.txt) and [paired counters](data/a.json).
- **Observation, memory.** bs_init reserves n² doubles for a basis in several batch paths, including states that ultimately contain only m vectors. One avoided proof state at 32×12800 alone requests 1,310,720,000 bytes of virtual address space. calloc reservation is distinct from resident memory and the surviving states still use square capacities. Source: bs_init_capacity, bs_init and bs_copy in src/bsolver_core.c.
- **Observation, thermal monitoring.** This VM exposes no thermal_zone temperature. CPU affinity and alternating order limit drift; A/A and cross-block dispersion quantify residual variability.
- **Observation from the review brief, canonical anchor.** For z=x+c under translation and the convention used for the translation direction, the anchor correction depends on the projection onto the normal space (the review's x−Pc for a shift of origin by c). See the exact bundle semantics in paper.tex. No translation-dependent change to the representation was evaluated.
- **Hypothesis from the review brief, Huang.** Relate the exact row projection/update to the Huang ABS algorithm under matching initialization and projector conventions. This comparison did not enter the rank-reuse argument.
- **Verified algebraically, homogeneous RHS.** With b=0, yᵀb=0 for every y, so a left-null inconsistency witness requiring yᵀb≠0 cannot apply. The homogeneous system contains x=0. This puts no extra constraint on the present full-row-rank proof. Source: inconsistency-witness definition in paper.tex.
